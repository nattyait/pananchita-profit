# ADR-0003: ProductKey falls back to "ชื่อสินค้า | ชื่อตัวเลือก"; parsers normalise cancellation; readers scan all sheets

Status: Accepted · Date: 2026-09-28

## Context
ไฟล์จริงจาก Shopee (ก.ย. 2026) แสดงว่า
1. ช่อง "เลขอ้างอิง SKU" และ "Parent SKU" ว่างทุกแถว เพราะร้านไม่ได้ตั้ง SKU ใน Seller Centre
2. รายงานรายรับมีข้อมูลรายออเดอร์อยู่ใน**ชีตที่ 2** (`Income`) ชีตแรกเป็นสรุป และไฟล์คำสั่งซื้อบันทึกขนาดตารางผิด
   ทำให้ openpyxl โหมด read-only เห็นแค่ 1 แถว
3. รายงานคำสั่งซื้อแบบ "ทั้งหมด" มีออเดอร์ที่ "ยกเลิกแล้ว" ซึ่งไม่ควรขึ้นเป็น "รอรับเงิน"
4. รายงานรายรับมีค่าหักเพิ่มที่ระบบยังไม่รู้จัก: ภาษี, ค่าธรรมเนียมโครงสร้างพื้นฐานแพลตฟอร์ม และค่าส่ง 3 คอลัมน์ที่หักล้างกัน

## Decision
1. **ProductKey** (คำใหม่ใน CONTEXT.md) คือตัวตนของสินค้าที่ใช้ผูกต้นทุน = SKU ถ้ามี; ถ้าว่าง = `"<ชื่อสินค้า> | <ชื่อตัวเลือก>"`
   (ตัดช่องว่างหัวท้าย; ไม่มีตัวเลือกก็ใช้ชื่อสินค้าอย่างเดียว) เก็บในฟิลด์เดิม `OrderLine.sku` และ `SkuCost.sku`
   เจ้าของเลือกทางนี้แทนการตั้ง SKU ใน Seller Centre; ถ้าวันหน้าตั้ง SKU ก็จะเปลี่ยนมาใช้ SKU โดยอัตโนมัติ
2. Parser ของแต่ละ platform ต้องแปลงสถานะเป็น `OrderLine.cancelled: bool` เอง (สถานะที่ถือว่ายกเลิกอยู่ใน yaml)
   เพราะ domain ห้ามรู้จักคำว่า "ยกเลิกแล้ว" ของ Shopee; `PendingOrder` ตัดออเดอร์ที่ทุกบรรทัดถูกยกเลิก
3. `report_reader` โหลดเต็มไฟล์ (ไม่ read-only) และคืน**ทุกชีต**; `mapping.find_header` เลือกชีต+แถวแรกที่มีหัวคอลัมน์ครบ
4. `Settlement` เพิ่ม `tax_fee`, `platform_fee`, `ads_fee` (ค่าเติมเงินโฆษณาที่ Shopee หักจากเงินโอน — เป็นค่าแอดที่ถูกหักไปแล้ว ไม่ต้องกรอกซ้ำในหน้า ค่าใช้จ่าย); `shipping_fee_diff` = ผลรวมของค่าส่งที่ผู้ซื้อจ่าย + ที่ Shopee ออกให้ + ที่ Shopee เรียกเก็บในชื่อร้าน
   (ปกติ = 0) `net_received` ยังอ่านจากคอลัมน์ "จำนวนเงินทั้งหมดที่โอนแล้ว" เท่านั้น ไม่คำนวณจาก breakdown
5. Schema เปลี่ยนแบบเพิ่มคอลัมน์เท่านั้น: `db.make_session_factory` เติมคอลัมน์ที่ขาดด้วย `ALTER TABLE … ADD COLUMN` (มี default)
   ก่อนเปิดใช้ — ปลอดภัยสำหรับ SQLite บน volume ที่มีข้อมูลอยู่แล้ว

## Consequences
- (+) ใช้ไฟล์จริงได้ทันทีโดยไม่ต้องแก้ข้อมูลใน Shopee; ผลรวมเดือน ก.ค. กระทบยอดกับ PDF ได้ (1,618)
- (−) ถ้าเปลี่ยนชื่อสินค้า/ตัวเลือกใน Shopee ต้องใส่ต้นทุนของ ProductKey ใหม่ (UI แสดงรายการที่ยังไม่มีต้นทุนอยู่แล้ว)
- (−) ออเดอร์ที่มีหลายสินค้ายังไม่แบ่งเงินลงต่อสินค้า — ADR ถัดไปเมื่อมีเคสจริง
